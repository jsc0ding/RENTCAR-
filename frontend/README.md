# Car Rental Frontend

React + Vite + TypeScript + Tailwind CSS bilan qurilgan avtomobil ijarasi frontend qismi.

## Texnologiyalar

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Shadcn/ui
- React Router
- React Query
- Axios

## O'rnatish

```bash
npm install
```

## Ishga tushirish

Development rejimida:
```bash
npm run dev
```

Build qilish:
```bash
npm run build
```

Build qilingan fayllarni ko'rish:
```bash
npm run preview
```

## Environment Variables

`.env` faylini yarating va quyidagi o'zgaruvchilarni qo'shing:

```
VITE_API_URL=http://localhost:5000/api
```
